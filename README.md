# Narrator (web)

Listen to PDF and EPUB files read aloud by natural AI voices (Kokoro) that run
entirely in your browser — on iPhone, iPad, Android, Mac or Windows.
Books are never uploaded anywhere.

**Open the app:** `https://<your-github-name>.github.io/narrator/`

- First start downloads about 90 MB of voice data (kept on the device).
- On iPhone: open in Safari → Share → **Add to Home Screen**, then open it from the icon.
- Tap the folder icon to open a PDF or EPUB (Files app, iCloud Drive or Dropbox).

Features: play/pause, back 10 s, forward 30 s, start, last 15 s; speed 0.25×–2×;
female/male voice (American or British); chapter menu from the book's own contents;
highlighted sentence with tap-to-read-from-here; remembered positions, bookmarks,
recent books, sleep timer, text size, light/dark theme, works offline after the first use.

Built with kokoro-js (Apache-2.0 model, MIT library), ONNX Runtime Web (MIT),
PDF.js (Apache-2.0) and JSZip (MIT).
